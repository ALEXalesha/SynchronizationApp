**SyncGlass 1.2.1: no more stutter, and checkboxes that look like the original.** Every problem below was found by measuring the real window on a copy of real data: 82 top-level folders and a size cache of 300,000 entries.

- **Quick actions no longer freeze the window.** Every refresh restarted the background size scan, and the scan started by re-reading the whole 49 MB size cache from disk and pouring 300,000 entries back into the window, although the window already had them. Switching the sort to date did the same, although sorting does not need sizes at all. The C# version's memory grew to 900 MB, and garbage collection froze the window for up to 1.6 seconds at a time. Now the cache is sent only to a window that has no sizes yet, and changing the sort only re-reads folder dates. Both versions.
- **History opens instantly (C#).** Expanding a history entry with 5,000 files took 8 seconds, because every row was built at once; now only the visible ones are, and it takes 14 ms. Opening a history of 200 runs went from 1.2 seconds to 65 ms for the same reason. The history file is now read off the window thread.
- **Expanding a folder is 7 times faster (C#).** The tree rebuilt its whole list on every expand and collapse; now it inserts or removes only the rows of that folder: 90 ms down to 13 ms per click.
- **Checkboxes like the original (C#).** A checked box shrank from 16 to 13 pixels, because WPF does not paint the background under the border the way Chromium does, and the tick was a hand-drawn line of its own. Both now match the Electron checkbox; a test compares 4x renders of the two.
- 257 C# tests and 202 JavaScript tests, all green.

Files: `SyncGlass-CSharp-Setup-1.2.1.exe` and `SyncGlass-CSharp-1.2.1-portable.exe` for the C# version, `SyncGlass Setup 1.2.1.exe` and `SyncGlass-1.2.1-portable.exe` for Electron. The builds are not code-signed, so SmartScreen may warn on first start.

**SyncGlass 1.2.1: без подтормаживаний, флажки как в оригинале.** Всё ниже найдено замером настоящего окна на копии настоящих данных: 82 папки верхнего уровня и кеш размеров на 300 тысяч записей.

- **Быстрые действия больше не подвешивают окно.** Каждое обновление перезапускало фоновый подсчёт размеров, а тот первым делом перечитывал с диска весь кеш на 49 МБ и заново вливал в окно 300 тысяч записей, которые там уже были. Переход на сортировку по дате делал то же самое, хотя сортировке размеры не нужны вовсе. Память C#-версии росла до 900 МБ, и сборка мусора останавливала окно до 1,6 секунды. Теперь кеш отдаётся только окну, где размеров ещё нет, а смена сортировки перечитывает только даты папок. В обеих версиях.
- **История открывается сразу (C#).** Раскрытие записи истории на 5000 файлов длилось 8 секунд: строились сразу все строки. Теперь только видимые - 14 мс. Открытие истории на 200 записей - 65 мс вместо 1,2 секунды. Файл истории читается не в потоке окна.
- **Раскрытие папки в 7 раз быстрее (C#).** Дерево пересобирало весь список на каждое раскрытие и сворачивание; теперь вставляет и убирает только строки этой папки: 13 мс вместо 90 на щелчок.
- **Флажки как в оригинале (C#).** Включённый флажок сжимался с 16 до 13 пикселей: WPF не красит фон под рамкой, а Chromium красит. И галочка была своей, кривой ломаной. Теперь оба вида совпадают с Electron; тест сравнивает их увеличенные в 4 раза кадры.
- 257 тестов C# и 202 JavaScript, все зелёные.
