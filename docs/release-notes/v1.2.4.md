**SyncGlass 1.2.4: an icon for the Electron version.**

- The Electron version had no icon of its own. The taskbar, the desktop shortcut and the installer showed the Electron atom. It now has its own icon: two circular arrows on glass in the window's accent colour. At 16-24 px the drawing is simpler and the lines are thicker, so it stays readable on the taskbar. The same drawing replaces the plain square logo in the window header.
- The C# version keeps its own icon (two panes with an arrow), so the two versions are easy to tell apart.
- New tests check that the icon file has every Windows size from 16 to 256, that the small frames are not empty and the arrows stand out from the background, and that the exe, installer, uninstaller and window all use it.
- 261 C# tests and 207 JavaScript tests, all green.

Files: `SyncGlass Setup 1.2.4.exe` and `SyncGlass-1.2.4-portable.exe` for Electron, `SyncGlass-CSharp-Setup-1.2.4.exe` and `SyncGlass-CSharp-1.2.4-portable.exe` for the C# version. The builds are not code-signed, so SmartScreen may warn on first start.

**SyncGlass 1.2.4: значок для Electron-версии.** У Electron-версии не было своего значка: в панели задач, на ярлыке и в установщике стоял атом Electron. Теперь свой - две стрелки по кругу на стекле цвета акцента окна; в 16-24 px рисунок проще и линии толще, чтобы значок читался в панели задач. Тот же рисунок стал логотипом в шапке окна вместо простого квадрата. У C#-версии значок остался прежний (две панели со стрелкой), так версии легко различить. Новые тесты проверяют, что в файле значка есть все размеры Windows от 16 до 256, что мелкие кадры не пустые и стрелки видны на фоне, и что exe, установщик, удаление и окно берут этот значок. 261 тест C# и 207 JavaScript.
