**SyncGlass now comes in two versions: the familiar Electron one and a new native C#/WPF one.**

- **C# version (new).** The same window, tree, preview, history and rules, rewritten in C# with WPF: a single `.exe` with no browser engine inside, a dark title bar of its own, rounded corners. Sizes and dates come straight from the folder listing, without a separate request per file, which matters on a network share.
- **Both versions share everything.** Settings, history, the size cache and the window position live in the same `%APPDATA%\SyncGlass` folder, in the same format. Switch between them at any time.
- **Only one runs at a time.** Both versions take the same single-instance lock, so the C# and Electron windows can never sync the same folders at once. Starting the second one brings the first to the front.
- **Light on memory with a big size cache.** The C# version reads and writes the size cache as a stream. On a real tree of 300,000 entries the first test build held 1.3 GB, because the 49 MB cache was loaded as one big text; the released one holds about 640 MB (the Electron version, about 550 MB), and a new test keeps the cache from being loaded as text again.
- **Checked the same way.** The C# version passes the same thirteen randomized laws as the Electron one, plus contract tests on files written by the Electron version itself. 248 C# tests and 199 JavaScript tests, all green.

Files: `SyncGlass-CSharp-Setup-1.2.0.exe` and `SyncGlass-CSharp-1.2.0-portable.exe` for the C# version, `SyncGlass Setup 1.2.0.exe` and `SyncGlass-1.2.0-portable.exe` for Electron. The builds are not code-signed, so SmartScreen may warn on first start.

**У SyncGlass теперь две версии: привычная на Electron и новая на C#/WPF.** Те же окно, дерево, предпросмотр, история и правила; C#-версия - один `.exe` без браузера внутри, со своим тёмным заголовком. Настройки, история, кеш размеров и место окна общие, в `%APPDATA%\SyncGlass`: переходить между версиями можно когда угодно. Запускается только одна: общий замок не даст двум окнам синхронизировать одно и то же. Кеш размеров C#-версия читает и пишет потоком: на настоящем дереве в 300 тысяч записей окно держит около 640 МБ, а не 1,3 ГБ, как первая проба. C#-версия проходит те же тринадцать законов на случайных деревьях. 248 тестов C# и 199 JavaScript.
